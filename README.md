# Totò — sito informativo OAuth

Sito statico pubblico e indipendente dall'applicazione privata Totò, destinato alla compilazione dei campi Branding di Google Auth Platform.

- Homepage: https://rickylat.github.io/
- Privacy: https://rickylat.github.io/privacy.html
- Termini: https://rickylat.github.io/terms.html

## Pubblicazione
1. GitHub repository Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
2. Verificare l'apertura pubblica dei tre URL.
3. Tentare Google Auth Platform -> Branding con questi URL e verificare se il dominio condiviso github.io è accettato.

Non pubblicare mai credenziali Google, token, codice JARVIS, SQLite o endpoint Tailscale.

Nota: la registrazione OAuth può rifiutare domini di hosting condiviso. In quel caso sarà necessario un dominio controllato personalmente, associabile a GitHub Pages. Controllare il contatto pubblico e le informazioni privacy prima di utilizzare il sito come documento ufficiale.
